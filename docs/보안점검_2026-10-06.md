# CRM Module 보안 점검 (OWASP Top 10 2021) — 2026-10-06

읽기 전용 감사 결과. 코드는 고치지 않았다. 비밀번호·키 **값은 적지 않고 위치만** 적었다. 경로는 저장소 루트 기준.
상위 항목(C1·H1·H3·M4)은 소스에서 직접 재확인했다.

- `integration/erp/controller/ErpLookupController.java:432-472` — `/api/lookup/employees` 가 인증만 되면 전 사원 사번·이름 반환 → ID 전수 확보.

## 오탐으로 제외한 항목
- Oracle 조회 레포지토리 SQL 인젝션 — 사용자 값은 전부 바인딩, `.replace("%…%")`·`%TBL%` 치환은 컴파일 타임 상수, ORDER BY 는 화이트리스트.
- ExcelService 수식 인젝션 — 문자열 셀이라 평가되지 않음.
- PDF 변환 커맨드 인젝션·경로 이탈 — basename + ProcessBuilder 인자 배열.
- 파일 업로드 경로 이탈 — basename + normalize + startsWith.
- JWT — HS512, 64바이트 미만·기본값 시 기동 거부, 서명 검증.
- 로그인 잠금(V155), 비밀번호 분실 타이밍 평탄화, Teams 임시 비밀번호 생성 — 적절.
