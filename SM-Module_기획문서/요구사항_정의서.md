## 2. 비기능 요구사항

| 요구사항 ID | 구분 | 요구사항명 | 상세 설명 | 우선순위 |
|------------|------|-----------|----------|---------|
| NFR-001 | 성능 | 동기화 처리 시간 | 마스터 데이터 전체 동기화가 10분 이내에 완료되어야 한다 | 상 |
| NFR-002 | 성능 | 트랜잭션 조회 응답 | ERP 데이터 조회 API가 3초 이내에 응답해야 한다 | 상 |
| NFR-003 | 성능 | 커넥션 풀 | Oracle 커넥션 풀 최대 5개로 ERP DB 부하를 제한한다 | 상 |
| NFR-004 | 가용성 | Oracle 장애 격리 | Oracle 연결 실패 시 SM Module 기본 기능(MariaDB)에 영향을 주지 않아야 한다 | 상 |
| NFR-005 | 가용성 | 재시도 메커니즘 | 연결 실패 시 30초 후 재시도, 최대 3회 | 상 |
| NFR-006 | 보안 | DB 접속정보 암호화 | Oracle 접속 비밀번호를 평문으로 저장하지 않는다 | 상 |
| NFR-007 | 보안 | 네트워크 보안 | EC2 → Oracle 통신은 방화벽으로 허용된 IP만 접속한다 | 상 |
| NFR-008 | 데이터 | 정합성 보장 | 마스터 데이터는 ERP 원본 기준, 트랜잭션은 최신 타임스탬프 기준 | 상 |
| NFR-009 | 데이터 | 감사 추적 | 모든 ERP 연동 작업은 실행일시, 결과, 처리건수를 기록한다 | 중 |
| NFR-010 | 운영 | 동기화 모니터링 | 동기화 상태를 대시보드에서 확인할 수 있어야 한다 | 중 |
