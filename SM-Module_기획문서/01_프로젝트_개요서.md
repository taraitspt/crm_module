# SM Module - Oracle ERP 연동 프로젝트 개요서

> 작성일: 2026-03-24
> 작성: HM소프트
> 시스템: SM Module (영업관리 시스템)
> 대상 ERP: 더존 iCUBE (Oracle 19c)

---

## 1. 프로젝트 배경

현재 SM Module(영업관리 시스템)은 자체 데이터베이스(MariaDB)에서 독립적으로 운영되고 있으며, 더존 iCUBE ERP와의 데이터 연동이 이루어지지 않고 있습니다.

이로 인해 다음과 같은 문제가 발생하고 있습니다:

- 주문/매출 데이터의 **이중 입력** (SM Module + ERP 각각 수동 입력)
- 거래처/품목/사원 마스터 데이터의 **불일치**
- 실시간 매출 현황 및 실적 파악의 **지연**
- 수주→출하→매출 프로세스 추적의 **단절**

---

## 2. 프로젝트 목표

SM Module과 Oracle ERP(더존 iCUBE) 간 **양방향 데이터 연동**을 구현하여:

1. **마스터 데이터 일원화**: 거래처, 품목, 사원/부서 정보를 ERP 기준으로 동기화
2. **트랜잭션 데이터 연동**: 주문, 수주, 출하, 매출 데이터를 실시간 공유
3. **업무 효율화**: 이중 입력 제거, 데이터 정합성 확보
4. **실시간 현황 파악**: ERP 매출/수주 데이터를 SM Module 대시보드에 반영

## 4. 연동 범위

### 4.1 ERP → SM Module (읽기)

| # | 데이터 | 설명 | 동기화 주기 |
|---|--------|------|------------|
| R1 | 거래처 마스터 | ERP 거래처 정보를 SM Module에 반영 | 1일 1회 |
| R2 | 품목 마스터 | ERP 품목 정보를 SM Module에 반영 | 1일 1회 |
| R3 | 사원/부서 정보 | ERP 조직 정보를 SM Module에 반영 | 1일 1회 |
| R4 | 수주 현황 | ERP 수주 데이터 조회 | 1시간 |
| R5 | 출하 현황 | ERP 출하 데이터 조회 | 1시간 |
| R6 | 매출(청구) 현황 | ERP 매출 데이터 조회 | 1시간 |

### 4.2 SM Module → ERP (쓰기)

| # | 데이터 | 설명 | 시점 |
|---|--------|------|------|
| W1 | 주문 등록 | SM에서 생성한 주문을 ERP에 반영 | 주문 생성 시 |
| W2 | 주문 수정 | SM에서 수정한 주문을 ERP에 반영 | 주문 수정 시 |
| W3 | 주문 상태 변경 | 상태 변경 내용을 ERP에 반영 | 상태 변경 시 |
| W4 | 외주발주 | SM에서 확정한 외주발주를 ERP에 반영 | 발주 확정 시 |
| W5 | 매출 확정 | SM에서 확정한 매출을 ERP에 반영 | 매출 확정 시 |

## 5. 구현 단계

| Phase | 내용 | 주요 산출물 |
|-------|------|-----------|
| **Phase 1** | Oracle 연결 기반 구축 | 듀얼 데이터소스 설정, 연결 테스트 |
| **Phase 2** | 마스터 데이터 동기화 | 거래처/품목/사원 동기화 기능 |
| **Phase 3** | 트랜잭션 데이터 동기화 | 수주/출하/매출 조회 기능 |
| **Phase 4** | SM → ERP 쓰기 기능 | 주문등록, 외주발주 ERP 반영 |
