## 1. SM Module 업무 프로세스 유형

### 프로세스 1: 외주/패키지/P&D

```
주문등록 ──→ 외주발주등록 ──→ 발주확정 ──→ 외주정산등록 ──→ 외주정산생성
   │              │              │              │              │
   │         (SM Module)    (SM→ERP)       (SM Module)    (SM Module)
   │                                                         │
   │                                                         ▼
   │                                          매입정산(전자결재) ──→ 매출등록 ──→ 세금계산서발행
   │                                             │              │              │
   │                                        (깃고 연동)     (SM→ERP)      (더존 연동)
```

### 프로세스 2: 구매

```
주문등록 ──→ 발주서작성 ──→ 확정처리 ──→ 구매정산등록 ──→ 매입정산(전자결재)
   │             │            │              │              │
   │        (SM Module)   (SM→ERP)      (SM Module)    (깃고 연동)
   │                                                       │
   │                                                       ▼
   │                                              매출등록 ──→ 세금계산서발행
   │                                                 │              │
   │                                             (SM→ERP)      (더존 연동)
```

### 프로세스 3: 내부생산(POD/센터)

```
주문목록 ──→ 발송완료 ──→ 매출등록 ──→ 세금계산서발행
   │            │            │              │
   │       (상태변경)    (SM→ERP)      (더존 연동)
```

## 3. SM Module ↔ ERP 연동 흐름

```
┌──────────────┐                           ┌──────────────┐
│  SM Module   │                           │  Oracle ERP  │
│              │                           │  (iCUBE)     │
│              │     [읽기: ERP → SM]      │              │
│  거래처관리  │ ←─── 거래처 동기화 ─────── │ CI_PARTNER   │
│  사원/부서   │ ←─── 사원/부서 동기화 ──── │ HR_EMP/DEPT  │
│  매출현황    │ ←─── 매출 데이터 ───────── │ SD_BILL_MST  │
│  수주현황    │ ←─── 수주 데이터 ───────── │ SD_SO_MST    │
│  출하현황    │ ←─── 출하 데이터 ───────── │ SD_DLV_MST   │
│  대시보드    │ ←─── 통계 데이터 ───────── │ 집계 쿼리    │
│              │                           │              │
│              │     [쓰기: SM → ERP]      │              │
│  주문등록    │ ────→ 주문 생성 ──────────→│ SD_ORDER_MST │
│  주문수정    │ ────→ 주문 수정 ──────────→│ SD_ORDER_MST │
│  외주발주    │ ────→ 발주 생성 ──────────→│ PU_PURORDER  │
│  매출확정    │ ────→ 매출 반영 ──────────→│ SD_BILL_MST  │
│              │                           │              │
│              │     [외부 연동]            │              │
│  세금계산서  │ ────→ 더존 API ──────────→ │              │
│  전자결재    │ ────→ 깃고 API ──────────→ │              │
└──────────────┘                           └──────────────┘
```

## 4. 주문번호 체계

| 시스템 | 접두어 | 형식 | 예시 |
|--------|--------|------|------|
| ERP 주문 (일반) | GOR | GOR + YYYYMMDD + 순번 | GOR2026032400374 |
| ERP 주문 (특수) | TOR | TOR + YYYYMMDD + 순번 | TOR202501020000011 |
| ERP 견적 | PRE | PRE + YYYYMMDD + 순번 | PRE2025010102342 |
| ERP 수주 | GSO/SO2/PSO/TSO | 접두어 + 순번 | GSO202501001 |
| ERP 출하 | DO | DO + YYYYMMDD + 순번 | DO2026031079 |
| ERP 매출 | BIL | BIL + YYYYMMDD + 순번 | BIL2025010001 |
| ERP 발주 | PUR | PUR + YYYYMMDD + 순번 | PUR2025010200001 |
