## 1. SM Module 시스템 현황

### 1.1 시스템 구성

| 구성요소 | 기술스택 | 비고 |
|---------|---------|------|
| Frontend | React SPA (Vite 빌드) | Ant Design UI, Recharts 차트 |
| Backend | Spring Boot 3.x + JPA/Hibernate | REST API, JWT 인증 |
| Database | MariaDB 10.5 | EC2 로컬 (3306 포트) |
| 서버 | AWS EC2 (Amazon Linux 2023) | Nginx 리버스 프록시 |
| 인증 | JWT + 2FA(이메일) + IP 화이트리스트 | 보안 강화 |

### 1.2 주요 기능 (메뉴 구성)

| 대분류 | 기능 | 설명 |
|--------|------|------|
| **대시보드** | 매출현황 | 누적매출, 주문건수, 거래처수, 마진율 요약 |
| | 매출추이 | 월별 매출 추이 차트 |
| | 최근주문 | 최근 등록된 주문 목록 |
| **주문관리** | 주문등록 | 주문 생성 (작업/품목 포함) |
| | 주문목록 | 주문 검색/조회/엑셀 다운로드 |
| **매출관리** | 매출목록 | 매출 조회/확정/변경이력 |
| | 선매출입력/목록 | 선매출 등록 및 조회 |
| | 카드매출 | 카드매출 조회 |
| **비대면주문** | 주문등록/목록 | 비대면 주문 생성 및 조회 |
| | 비대면정산 | 비대면 결제/정산 관리 |
| **매입마감** | 외주발주 | 외주발주 관리/PDF 출력 |
| | 외주정산 | 외주정산 등록/엑셀 업로드/전자결재 연동 |
| **세금계산서** | 발행/목록 | 더존 연동 세금계산서 발행 |
| **정보관리** | 거래처관리 | 사업자/고객(담당자) CRUD |
| | 목표입력 | 파트목표/AM목표 입력 (통합 예정) |
| **통계** | 목표 vs 실적 | 파트/AM 목표 대비 실적 (전년비교) |
| | 팀예측/팀목표실적 | 팀별 예상매출, 목표 대 실적 |
| | 마진분석 | 주문별/업체별 마진 분석 |
| | 품목실적 | 품목별 실적 분석 |
| **관리** | IP화이트리스트 | IP 접근제어 관리 |

### 1.3 SM Module 데이터베이스 (MariaDB)

| 테이블 | 설명 | 비고 |
|--------|------|------|
| `departments` | 부서/파트 | 조직 관리 |
| `users` | 사용자 | 사원번호, 역할, 부서 연결 |
| `business_owners` | 사업자(거래처) | 사업자번호, 더존코드 |
| `customers` | 고객(담당자) | 사업자 하위 담당자 |
| `orders` | 주문 | 주문번호, 거래처, 금액 |
| `order_works` | 주문-작업 | 작업유형, 작업명, 금액 |
| `order_items` | 주문-품목 | 품목, 수량, 단가 |
| `sales` | 매출 | 주문 연결, 매출확정 |
| `card_sales` | 카드매출 | 카드사, 승인번호 |
| `pre_sales` | 선매출 | 선매출번호, 잔액 |
| `untact_orders` | 비대면주문 | 비대면 결제 |
| `untact_settlements` | 비대면정산 | 결제/정산 금액 |
| `outsourcing_pos` | 외주발주 | 발주번호, 외주금액 |
| `outsourcing_settlements` | 외주정산 | 수량, 단가, 전자결재 |
| `tax_invoices` | 세금계산서 | 발행번호, 더존 연동 |
| `part_goals` | 파트목표 | 부서별 월별 목표 |
| `am_goals` | AM목표 | 담당자별 월별 목표 |
