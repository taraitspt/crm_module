1. WBS 개요

본 문서는 SM Module - Oracle ERP 연동 프로젝트의 작업분류체계(WBS, Work Breakdown Structure)를 정의합니다. 프로젝트는 총 6개 단계(Phase)로 구성되며, 50개 이상의 세부 작업(Task)을 포함합니다. 각 단계는 프로젝트 관리, 분석, 설계, 개발, 테스트, 이행/배포로 분류되며, 단계별 선행관계와 담당자, 산출물이 명확히 정의되어 있습니다. WBS는 프로젝트 전 과정에 걸쳐 진행 현황을 추적하고, 일정 관리 및 리소스 배분의 기준 문서로 활용됩니다.

5. 선결과제 (Critical)

프로젝트 진행을 위해 반드시 사전 해결되어야 하는 핵심 과제입니다.

프로젝트 선결과제 (Pre-requisites)

  1. EC2 → Oracle 방화벽 개방
    EC2 IP: 3.35.116.156 → Oracle: 39.125.168.136:15253
    운영 환경에서 Oracle ERP에 접속하기 위한 네트워크 방화벽 개방이 필요합니다.
  2. Oracle COMET 계정 INSERT/UPDATE 권한 확인
    현재 COMET 계정의 읽기 권한은 확인되었으나, SM Module에서 ERP로 데이터를 쓰기 위한 INSERT/UPDATE 권한 여부가 미확인 상태입니다.
  3. SM Module 소스코드 Git 저장소 구성
    현재 빌드 결과물(JAR)만 존재하며, 소스코드 Git 저장소가 구성되어 있지 않습니다. 형상관리를 위한 Git 저장소 구성이 선행되어야 합니다.
  4. ERP 거래처코드(PARTNER_CD) ↔ SM 사업자번호 매핑 규칙 확정
    ERP의 거래처 코드 체계와 SM Module의 사업자번호 간 매핑 규칙이 확정되어야 거래처 동기화 개발이 가능합니다.
  5. iCUBE 주문 생성 시 필수 필드/비즈니스 로직 확인
    SM Module에서 ERP(iCUBE)로 주문을 생성할 때 필수 입력 필드와 비즈니스 로직(채번 규칙, 상태 코드 등)에 대한 확인이 필요합니다.
참고: 위 선결과제들은 프로젝트 일정에 직접적인 영향을 미치는 항목으로, 설계 단계 진입 전까지 해결이 완료되어야 합니다. 특히 1번(방화벽)과 2번(계정 권한)은 외부 의존성이 있으므로 조기 요청이 필요합니다.
