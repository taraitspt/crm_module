1. SM Module 업무 프로세스 유형

SM Module은 3가지 주요 업무 프로세스 유형으로 운영됩니다. 각 프로세스는 주문 유형에 따라 처리 경로가 상이하며, Oracle ERP 및 외부시스템과의 연동 구간이 포함됩니다.

5. 주문번호 체계

Oracle ERP에서 사용하는 각 문서의 번호 체계입니다. 접두어를 통해 문서 유형을 식별할 수 있으며, 주문(GOR)이 가장 많은 건수를 차지합니다.

시스템 접두어 형식 예시 비고
ERP 주문 (일반) GOR GOR + YYYYMMDD + 5자리 GOR2026032400374 가장 많음 (107,395건)
ERP 주문 (특수) TOR TOR + YYYYMMDD + 순번 TOR202501020000011 9,449건
ERP 견적 PRE PRE + YYYYMMDD + 순번 PRE2025010102342
ERP 수주 GSO / SO2 / PSO / TSO 접두어 + 순번 GSO202501001
ERP 출하 DO DO + YYYYMMDD + 순번 DO2026031079
ERP 매출 BIL BIL + YYYYMMDD + 순번 BIL2025010001
ERP 발주 PUR PUR + YYYYMMDD + 순번 PUR2025010200001

7. 데이터 모델 매핑 (신규 타겟 스키마)

각 업무 프로세스 단계에서 사용되는 신규 타겟 DB 테이블을 매핑합니다. 모든 테이블은 company_cd + plant_cd 복합키를 선두 컬럼으로 사용하여 ERP 멀티컴퍼니 구조와 정렬됩니다. (참고: dbdiagram.io 스키마)

# 프로세스 단계 관련 타겟 테이블 테이블 역할 설명
1 주문등록 order_mst + order_dtl + order_info + order_dlv + file_info order_mst: 주문 마스터 (주문번호, 거래처, 담당자, 주문일 등)
order_dtl: 주문 디테일 (순번별 품목, 수량, 단가, 금액, 상태)
order_info: 주문 상세사양 (용지/원자재 구분, 인쇄도수, 작업코드, 외주업체 등)
order_dlv: 납품/배송 정보 (수량, 배송방법, 수령자, 주소)
file_info: 첨부파일 (파일명, 경로, 확장자, 사이즈)
2 외주발주등록 po_mst + po_dtl po_mst: 발주 마스터 (발주번호, 연결 주문번호, 수량, 금액, 납품일, 발주상태)
po_dtl: 발주 디테일 (순번별 외주거래처, 수량, 단가, 금액, 정산상태: 미정산/정산/매입완료)
3 정산생성 po_settle_mst + po_settle_dtl po_settle_mst: 정산 마스터 (정산번호, 정산일, 정산금액, 매입전표번호)
  • gitgo_sync_status (PENDING/SYNCED/FAILED): 깃고 전자결재 연동 상태 추적
po_settle_dtl: 정산 디테일 (정산수량, 정산금액, 연결 발주번호/주문번호)
4 매출등록 sales_mst + sales_dtl sales_mst: 매출 마스터 (매출번호 BIL..., 거래처, 매출타입, 결제방식, 매출일, 총금액, 매출전표번호)
  • erp_sync_status (PENDING/SYNCED/FAILED): 더존 ERP 연동 상태 추적
sales_dtl: 매출 디테일 (연결 주문번호, 수량, 단가, 금액)
5 목표입력 goal_mst goal_mst: 목표 통합 테이블 (연도, 월, 부서, 담당자, 거래처, 목표금액)
  • field_cd: 내부(파트목표) / 외부(AM목표) 구분 — 기존 2개 테이블을 1개로 통합
  • PK: company_cd + plant_cd + plan_yy + plan_mm + dept_cd + sales_emp_id + field_cd
테이블 관계 요약 (Ref):
order_mst → order_dtl → order_info (3계층 마스터-디테일)
order_dtl → order_dlv, file_info (납품/파일 연결)
po_mst → po_dtl → order_info (발주-주문상세 연결)
po_settle_mst → po_settle_dtl → po_dtl (정산-발주 연결)
sales_mst → sales_dtl → order_dtl (매출-주문디테일 연결)
