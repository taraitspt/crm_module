1. 문서 개요

본 문서는 SM Module - Oracle ERP 연동 프로젝트에서 사용되는 데이터베이스 테이블의 구조를 정의합니다. SM Module은 MariaDB를 주 데이터베이스로 사용하며, Oracle 19c 기반의 더존 ERP 시스템과 실시간/배치 연동을 수행합니다. 기존 SM Module 테이블, 신규 설계 테이블(Target DB), 신규 추가 테이블(ERP 연동용), 그리고 Oracle ERP 핵심 참조 테이블을 포함합니다.

참고: SM Module 테이블은 Flyway를 통한 버전 관리 마이그레이션으로 생성됩니다. Oracle ERP 테이블은 더존 ERP 시스템 소유이며, SM Module에서는 DB Link 또는 API를 통해 접근합니다.

2. SM Module 신규 설계 스키마 (Target DB 설계)

TARGET 스키마 안내: 본 섹션은 SM Module 시스템 재설계를 위한 목표(Target) 데이터베이스 스키마입니다. 기존 JAR 분석 기반 테이블(섹션 3)을 대체하는 신규 설계이며, 더존 ERP(Oracle) 체계에 맞춘 company_cd + plant_cd 복합 PK 구조를 채택합니다. 모든 테이블은 MariaDB에서 운영되며, Master/Detail 패턴으로 정규화되어 있습니다.

dbdiagram.io 설계 원본: https://dbdiagram.io/d/69ae32f7f18be96a591e82db

핵심 설계 원칙

  • ERP 정렬 복합 PK: 모든 테이블이 company_cd(회사코드) + plant_cd(공장코드)를 PK에 포함하여 ERP 멀티 회사/공장 구조와 일치
  • Master/Detail 패턴: order_mst → order_dtl → order_info, po_mst → po_dtl, sales_mst → sales_dtl, po_settle_mst → po_settle_dtl
  • 목표 통합: goal_mst가 파트목표/AM목표를 field_cd 구분으로 단일 테이블에 통합
  • ERP 동기화 추적: sales_mst에 erp_sync_status ENUM(PENDING/SYNCED/FAILED)으로 더존 ERP 연동 상태 관리
  • 깃고 동기화 추적: po_settle_mst에 gitgo_sync_status ENUM(PENDING/SYNCED/FAILED)으로 깃고 연동 상태 관리
  • 14개 테이블, 11개 관계: 주문/발주/정산/매출 도메인을 완전히 커버하는 정규화된 스키마

5. Oracle ERP 핵심 테이블 (Oracle 19c)

더존 ERP 시스템(Oracle 19c)의 핵심 참조 테이블입니다. SM Module에서 DB Link 또는 전용 API를 통해 읽기/쓰기 접근합니다. 아래 테이블 구조는 실제 ERP 스키마 분석 결과 기반이며, 주요 컬럼만 포함합니다.
